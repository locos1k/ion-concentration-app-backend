# ion-concentration-app-backend

Бэкенд для лабораторной по РИП. Тема — растворы электролитов (кислоты, щёлочи, соли):
их можно листать лентой, смотреть черновик на странице добавления и искать в каталоге
по молярной концентрации.

Стек: **NestJS** + **Handlebars** для шаблонов, **MinIO** для фото и видео. Никакой базы
данных и никакого JavaScript на страницах — всё через HTML и CSS.

## Запуск

```bash
npm install
docker compose up -d minio   # если ещё не поднят
npm run start:dev
```

Приложение поднимется на `http://localhost:3000` и сразу перекинет на `/solutions`.

## Что где лежит

- `src/solutions/` — вся логика: модель раствора, сервис с данными и фильтром, контроллер с роутами
- `views/` — три Handlebars-шаблона (лента, добавление, плитка) + общие куски в `views/partials`
- `public/` — CSS и картинка лайка
- `docker-compose.yml` — MinIO (хранилище фото и видео)

## Страницы

Все адреса начинаются с `/solutions`:

- **`/solutions`** и **`/solutions/:id?next=true`** — лента. Открывается видео с первым
  раствором, стрелка «дальше» листает по кругу.
- **`/solutions/draft`** — страница добавления. Показывает единственный черновик
  в коллекции, поля можно менять, но кнопка сохранения не работает (сохранение — уже
  следующая лабораторная).
- **`/solutions/list?min=&max=`** — каталог, 2 колонки карточек. Сверху двойной
  ползунок — фильтрует растворы по диапазону молярной концентрации прямо на сервере.

Раствор в статусе `draft` виден только на странице добавления, `deleted` — нигде.

## Как раствор устроен

У каждого раствора: название, формула, тип (кислота/основание/соль), молярная
концентрация, pH, описание, фото и видео в MinIO (хранятся как имя файла, а не
как ссылка целиком) и список id пользователей, которые лайкнули.

## Без JavaScript — как это сделано

- «Ещё» у описания на ленте — обычный `<details>`, браузер сам разворачивает текст
- Двойной ползунок в каталоге — два `<input type="range">` друг на друге, кликается
  только сам бегунок
- Листание ленты — просто ссылки со `?next=true`, страница перезагружается

## MinIO

Фото и видео берутся из бакета `solution-assets` (поднимается вместе с
`docker-compose.yml`, S3 на порту 9000, консоль — на 9001). Адрес бакета можно
поменять переменной окружения `MEDIA_BASE_URL`.

## Дизайн

Тёмная тема, вдохновлено TikTok: чёрный фон, зелёный акцент `#4BDE81`, карточки
со скруглёнными углами. Всё в одном файле `public/css/style.css`.
